# Internet Outage Response

## Purpose

Provide a safe first-response process for clinic staff and managers while giving IT the evidence needed to restore service quickly.

## Clinic Staff — First Five Minutes

- [ ] Confirm whether the problem affects one device, one area, or the entire site.
- [ ] Check whether wired devices, Wi-Fi devices, and phones are affected.
- [ ] Record the time the problem began and any visible error message.
- [ ] Check power only; do not unplug or reset network equipment unless IT directs it.
- [ ] Test one approved public website from a second device if possible.
- [ ] Notify the clinic manager through the established channel.

## Clinic Manager

- [ ] Confirm operational impact and affected services.
- [ ] Submit one request to IT with the site, start time, scope, and callback contact.
- [ ] Avoid opening duplicate requests or contacting providers independently unless the continuity plan requires it.
- [ ] Activate the approved downtime workflow when directed.
- [ ] Provide staff with a consistent status update.

## IT Triage

1. Confirm the affected location and impact.
2. Check monitoring, provider status, and recent changes.
3. Verify power and indicators with an authorized on-site contact.
4. Test the provider handoff, router, switch, wireless, and DNS path as appropriate.
5. Separate Internet failure from local network, application, or device failure.
6. Apply a safe workaround when available.
7. Escalate through the documented carrier or vendor path.
8. Communicate the next update time even when there is no new resolution estimate.

- [ ] Service restored and tested from more than one device
- [ ] Voice and critical applications checked

- [ ] Root cause and follow-up action recorded
