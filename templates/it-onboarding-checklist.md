# IT Onboarding Checklist

> Generic portfolio template. Adapt it to approved HR, privacy, identity, and security requirements.

## 1. Request Information

- [ ] Approved request received from HR or the authorized manager
- [ ] Legal name and preferred display name confirmed
- [ ] Start date, location, department, and manager confirmed
- [ ] Employment type and expected end date, if temporary, confirmed
- [ ] Required role and systems identified
- [ ] Special privacy, accessibility, or remote-work requirements recorded

## 2. Access Approval

- [ ] Access based on a documented role or approved exception
- [ ] Email and collaboration license approved
- [ ] Business applications approved by the application owner
- [ ] Shared mailbox and group membership approved
- [ ] Administrative access separately justified and approved
- [ ] Multifactor authentication method planned

## 3. Equipment

- [ ] Role-based device selected
- [ ] Asset record updated
- [ ] Operating system and firmware current
- [ ] Encryption enabled and verified
- [ ] RMM and endpoint protection active
- [ ] Standard applications installed
- [ ] Printers, voice, and peripherals tested if required
- [ ] Assignment or handover acknowledged by manager or Operations

## 4. Account Setup

- [ ] Identity created using the approved naming standard
- [ ] Temporary credentials shared through an approved secure method
- [ ] Password reset or first-login process enforced
- [ ] MFA enrollment completed
- [ ] Required groups and applications assigned
- [ ] Unnecessary access confirmed absent

## 5. Validation and Handover

- [ ] User can sign in
- [ ] Email, required applications, and remote access tested
- [ ] Security and support instructions provided
- [ ] Manager confirms operational readiness
- [ ] Request record closed with completion date and exceptions
